# 🎓 Scholarship Portal

A centralized platform for discovering and managing scholarship opportunities.

## ✨ Features
* **Search & Filter:** Find scholarships by major, eligibility, and deadline.
* **User Profiles:** Save favorites and track application status.
* **Admin Dashboard:** Tools for posting and verifying new listings.
